# SVG 示意图排版规则

画图前按此规划坐标，自检时按此核对。核心一句话：**先估算、再落笔**——SVG 没有自动排版，一切位置都是手算的。

## 1. 文本估宽（最重要）

- 中文/全角字符宽 ≈ 字号（px）；ASCII 字母/数字 ≈ 0.55 × 字号。
- 行宽 ≈ Σ(字符宽) + 左右各 6px 内边距。
- `text-anchor:middle`：确认 [中心 − 半宽, 中心 + 半宽] 不越出所属容器、不与相邻元素重叠。
- `text-anchor:end`：起点 = 右端点 − 行宽，确认 x ≥ 4 不越出 viewBox 左缘。
- SVG `<text>` **不会自动换行**：长句要么手动拆成多个 `<text>`（行距 1.5 × 字号），要么移进 HTML 图注 `.cap`。

## 2. 几何与网格

- 坐标取 10px 网格，viewBox 四周留 ≥ 16px 空白。
- **最后一行文本的基线 y ≤ viewBox 高 − 8**，越界就加高 viewBox（底部文字被裁是最常见 bug）。
- 盒子间距 ≥ 12px；文字到盒边内边距 ≥ 6px（基线到盒底 ≥ 6px）。
- 平行走线错开 ≥ 6px，不共用同一 y/x；polyline 的水平段不要穿过其他盒子或文字。
- 字号阶梯：小标题 13 / 正文 12 / 辅助注释 10–11；最小 9——再小就删内容，不要缩字号。

## 3. 语义配色（本仓库文档约定）

| 用途 | 颜色 |
|---|---|
| 主强调 / 蓝轨 C_a | `#2456c4`（浅底 `#eef3fc`） |
| 橙轨 C_b / 次强调 | `#e8862a`（浅底 `#fbe3cc`） |
| 门控 / 权重 / 绿色系 | `#2f9e63`（浅底 `#d9f0e2`） |
| HCA / 深蓝 | `#163a86` |
| 正文 / 辅助文字 | `#1a1f2e` / `#5a6272` |
| 中性边框 / 灰盒 | `#c9d2e0` / `#f6f8fa` |

- 高亮用「虚线框 + 半透明填充」，不要叠粗实线框。
- `<defs>` 与 marker id 每张图自带，id 带图号前缀（`m3a`、`m3b`…）——HTML 里 id 是全局命名空间，跨图重名会让箭头 marker 串用。

## 4. 结构约定

- 每张图外包 `.fig` 容器；图注放 `.cap`（HTML 文字，可长），图内只留必要标签。
- 同列盒子同 x 同宽；同类标签同字号同色。
- 箭头终点落在目标盒边缘 2px 以内，不悬空、不插入盒内。

## 5. 自检与终审

静态检查（必过）：`python3 .qoder/skills/svg-figure/scripts/check_svg.py <page.html>`，修到 0 错误 0 警告。它按估宽的包围盒抓：四边裁剪、文本互叠、文本骑框、字号 < 9、重复 id、缺 viewBox。估宽有 ±10% 误差，报出来的必须修，没报不等于没问题。

浏览器终审（`open` 页面后人工核对，静态检查不覆盖的都在这）：

1. 对齐与间距是否均匀、留白是否舒服；
2. 箭头起止是否落在目标盒边缘 2px 内、方向是否正确；
3. 配色与字号是否与全文档一致；
4. 跨图 marker 颜色是否串用（检查器抓 dup-id，但抓不了 id 拼错指向别的图）；
5. 整体视觉密度——太挤就加 viewBox 或删内容，不要缩字号。

DeepSeek mHC 解读：流形约束超连接（Manifold-Constrained Hyper-Connections）

日期：2026-09-14（09-15 增补 §2.2 约束机制详解）　论文：mHC: Manifold-Constrained Hyper-Connections（DeepSeek-AI，Zhenda Xie 等）

本地文件：paper/mhc.pdf（主论文，19 页）；paper/deepseek_v4.pdf（§2.2、§3.4.2 落地）；paper/deepseek_v41.pdf（§2.4.1 Single-Pass mHC）

TL;DR：Hyper-Connections（HC）把残差流宽度从 \(d\) 扩到 \(n\times d\)，用三个可学习映射管理「读出 / 流内混合 / 写入」，FLOPs 几乎不涨但性能显著提升；代价是层间复合映射不再守恒，信号增益失控（27B 模型实测峰值约 3000 倍），大规模训练出现 loss surge，且 n 流设计把显存读写放大约 n 倍。mHC 的解法非常克制：只把流内混合矩阵 \(B_l\)（即 \(H^{res}\)）用 Sinkhorn-Knopp 算法投影到双随机矩阵流形（Birkhoff 多胞体）——行和 = 列和 = 1、非负。由此谱范数 ≤ 1（前向非扩张）、乘法封闭（任意深度复合仍守恒）、\(B_l x\) 成为各流的凸组合（可混合但均值守恒）；\(n=1\) 时恰好退化为原始恒等映射。消融显示 \(H^{res}\) 贡献了 HC 绝大部分收益（−0.022 / 总 −0.027 loss gap），所以只严格约束它、保住表达力。27B 实验：复合映射增益从 ~3000 降到 ~1.6（三个数量级），最终 loss 比 baseline 低 0.021，8 项下游基准全面超 baseline、多数超 HC（BBH +2.1、DROP +2.3 vs HC）；n=4 时大规模训练仅 +6.7% 墙钟开销。mHC 已进入生产：DeepSeek-V4（1.6T-Pro / 284B-Flash）全面采用，DeepSeek-V4.1 进一步升级为 Single-Pass mHC + Mega-mHC 单内核，激活显存流量减半，45T token 训练全程无不稳定。

1. 解决什么问题

1.1 背景：恒等映射与 HC 的「加宽」

标准残差 \(x_{l+1} = x_l + F(x_l, W_l)\)（式 1）多层展开后，浅层信号 \(\ x_l\) 以恒等映射直达深层（式 2）——这是 ResNet 以来大规模训练稳定性的基石（He et al. 2016b）。Hyper-Connections（HC，Zhu et al. 2024）在不动层内计算的前提下把残差流从 \(d\) 维加宽到 \(n\times d\)（n 个流，n=4），并引入三个可学习映射（式 3）：

\[ x_{l+1} = H^{res}_l\, x_l + (H^{post}_l)^{\!\top} F\!\left(H^{pre}_l\, x_l,\ W_l\right) \]
  • \(H^{pre}_l \in \mathbb{R}^{1\times n}\)：把 n 个流读出成层输入；
  • \(H^{post}_l \in \mathbb{R}^{1\times n}\)：把层输出写回各流；
  • \(H^{res}_l \in \mathbb{R}^{n\times n}\)：流之间的混合（残差映射）。

每个映射由「动态分量（依赖输入的 \(\tanh(\theta \tilde{x}^{\!\top})\)）+ 静态分量（bias \(b\)）」构成，门控 \(\alpha\) 初始化为小值。由于 \(n=4 \ll d\)，这些映射的 FLOPs 可忽略——HC 本质上给模型加了一条解耦于计算量的容量扩展轴。论文的消融（Table 1）指明了收益来源：

\(H^{res}_l\)\(H^{pre}_l\)\(H^{post}_l\)Absolute Loss Gap
✓−0.022
✓✓−0.025
✓✓✓−0.027

表 1｜HC 组件消融（论文 Table 1）。禁用某映射时以固定映射保持维度一致：\(H^{pre}\) 用均匀 1/n、\(H^{post}\) 用全 1、\(H^{res}\) 用单位阵。仅 \(H^{res}\) 一项就贡献了 −0.022（约八成收益）——这直接决定了 mHC「只严格约束 \(H^{res}\)」的设计取舍。

1.2 问题一：复合映射失控 → 训练不稳定

把 HC 递归展开到 L 层（式 4），浅层到深层的有效信号传播由复合映射 \(\prod_{i=1}^{L-l} H^{res}_{L-i}\) 决定。标准残差里它是恒等映射（严格守恒），而 HC 的 \(H^{res}\) 无约束，复合后信号幅度 prone to 爆炸或消失。论文用 Amax Gain Magnitude 量化：复合矩阵的最大绝对行和（前向信号增益）与最大绝对列和（反向梯度增益）。

  • 27B 模型实测（论文 Fig 3）：单层 \(H^{res}\) 的增益已偏离 1，复合映射增益峰值接近 3000——残差流在层间爆炸；
  • 训练动态（Fig 2）：HC 在约 12k 步出现 loss surge，梯度范数飙到 0.2+；同规模的 mHC 平稳。

1.3 问题二：n 流设计的系统开销

FLOPs 不涨不等于快。n 流设计成倍放大显存读写（I/O）——现代加速器的主要瓶颈（"memory wall"）。论文 Table 2 给出单层每 token 的 I/O 对比：

标准残差（Residual Merge）\(2C\)\(C\)2C / C
HC（系数计算 + 读出 + 写回 + 残差合并）\((5n{+}1)C + n^2 + 2n\)\((3n{+}1)C + n^2 + 2n\)21C / 13C（≈10× 读）

表 2｜每 token 显存访问开销（论文 Table 2 + §4.3.1，只计残差流维护、不含层函数 \(F\) 内部）。HC 把读放大到约 10 倍；mHC 把 \(H^{post}\) 写回、\(H^{res}\) 混合与残差合并融合为一个 kernel，大幅回收。此外 HC 的可学习系数需要为反向保留中间激活（显存大增）、流水线并行通信量翻 n 倍。

2. 设计是什么

2.1 核心约束：把 \(H^{res}\) 投影到 Birkhoff 多胞体

mHC 的主张是：稳定性不需要退回恒等映射，只需要复合映射不放大信号；而流间信息交换（HC 收益的来源）必须保留。同时满足两者的最小约束集是双随机矩阵——非负、行和与列和均为 1（式 6）：

\[ \mathcal{M}_{res} = \left\{\, H \in \mathbb{R}^{n\times n} \;\middle|\; H\mathbf{1}_n = \mathbf{1}_n,\ \mathbf{1}_n^{\!\top} H = \mathbf{1}_n^{\!\top},\ H \geqslant 0 \,\right\},\qquad H^{res}_l = \mathcal{P}_{\mathcal{M}_{res}}(\tilde H^{res}_l) \]

这组约束带来三条严格性质（论文 §4.1）：

  1. 谱范数 ≤ 1：\(\|H^{res}_l\|_2 \le 1\)，映射非扩张（non-expansive），前向不放大信号、抑制梯度爆炸；
  2. 乘法封闭：双随机矩阵对矩阵乘法封闭，任意深度的复合映射 \(\prod H^{res}\) 仍是双随机的——稳定性不随深度衰减；
  3. 几何解释：\(\mathcal{M}_{res}\) 即 Birkhoff 多胞体（置换矩阵的凸包），\(H^{res} x\) 是各流的凸组合——信息可以混合，但特征均值守恒；反复应用会单调增加流间混合，相当于一个稳健的特征融合机制。

关键的性质检查：\(n=1\) 时双随机条件退化为标量 1，恰好恢复原始残差的恒等映射——mHC 是残差连接的严格泛化，而非另一个孤立设计。另外 \(H^{pre}\)、\(H^{post}\) 加非负有界约束（\(H^{pre}=\sigma(\cdot)\)、\(H^{post}=2\sigma(\cdot)\)），防止正负系数叠加造成信号抵消。

图 1｜三种残差范式（仿论文 Fig 1）。残差连接靠恒等透传保证守恒；HC 用无约束可学习映射换取表达力，牺牲了守恒；mHC 只把流内混合 \(H^{res}\) 约束到双随机流形——「可混合、不放大」，读出/写回通道仅加轻量非负有界约束。

2.2 参数化与 Sinkhorn-Knopp 投影

约束如何参与梯度训练？mHC 的做法与神经网络里一切「约束出口」的技巧同源——要概率分布就接 softmax、要正数就接 σ：参数与原始系数完全自由，只在出口处放一个可微投影，保证送出去的 \(H^{res}\) 永远落在流形上。具体而言，把「生成无约束原始系数 → 投影」做成可微流水线（式 7–8）。把流矩阵展平为 \(\bar{x}_l = \mathrm{vec}(x_l) \in \mathbb{R}^{nC}\)（保留全部流信息），归一化后经线性投影产生动态分量，加静态 bias（式 7）：

\[ \bar{x}'_l = \mathrm{RMSNorm}(\bar{x}_l);\quad \tilde H^{pre}_l = \alpha^{pre}_l (\bar{x}'_l \varphi^{pre}_l) + b^{pre}_l,\quad \tilde H^{post}_l = \alpha^{post}_l (\bar{x}'_l \varphi^{post}_l) + b^{post}_l,\quad \tilde H^{res}_l = \alpha^{res}_l\, \mathrm{mat}(\bar{x}'_l \varphi^{res}_l) + b^{res}_l \]

其中 \(\varphi^{pre},\varphi^{post} \in \mathbb{R}^{nC\times n}\)、\(\varphi^{res} \in \mathbb{R}^{nC\times n^2}\)，\(\mathrm{mat}(\cdot)\) 把 \(n^2\) 维向量重塑为 \(n\times n\) 矩阵。然后施加约束（式 8）：

\[ H^{pre}_l = \sigma(\tilde H^{pre}_l),\qquad H^{post}_l = 2\sigma(\tilde H^{post}_l),\qquad H^{res}_l = \mathrm{Sinkhorn\!-\!Knopp}(\tilde H^{res}_l) \]

为什么用「出口投影」，而不是别的方式加约束

\(H^{res}\) 是逐 token 动态生成的：出口矩阵每层、每个 token 都不同，约束的作用对象只能是出口矩阵而非参数——参数合法不代表生成的矩阵合法。这排除了几种直觉做法：

  • 加正则项：惩罚偏离双随机的程度是软约束，只在梯度尺度上施压，任何时刻都可能被其他损失项压过，还引入需要调的惩罚权重；出口投影无超参、任何时刻严格合法；
  • 行 softmax 直接参数化：出口矩阵逐行过 softmax——行和 = 1 有了，列和没人管。而稳定性恰恰两头都要（行和对应前向信号增益、列和对应反向梯度增益，见 §1.2 的 Amax Gain 度量），想同时精确满足行列两个约束，几乎绕不开交替归一化；
  • 欧氏投影到 Birkhoff 多胞体：每步要解一个二次规划，对逐 token、逐层的调用频率太贵。Sinkhorn 是它的廉价替代——指数化入口对应熵正则化的流形投影。

Sinkhorn-Knopp 是什么

1967 年的经典算法（Sinkhorn & Knopp），功能单一：把任意正矩阵交替归一化，收敛到双随机矩阵。投影（式 9）先取 \(M^{(0)} = \exp(\tilde H^{res}_l)\) 逐元素指数化保证正性，再交替做行/列归一化：

\[ M^{(t)} = T_r\!\left(T_c(M^{(t-1)})\right) \]

两步交替：行归一化让行和全变 1 但破坏列和；列归一化让列和全变 1 但又破坏行和——振荡着向「同时满足」逼近。拿 \(2\times 2\) 手算两轮就有体感（exp 输出必为正，不妨直接从一个正矩阵出发）：

初始  M0 = [[1.00, 2.00],
            [3.00, 4.00]]

第 1 轮：
  行归一化 → [[0.333, 0.667], [0.429, 0.571]]    行和 = 1 ✓，列和 = [0.76, 1.24] ✗
  列归一化 → [[0.4375, 0.5385], [0.5625, 0.4615]] 列和 = 1 ✓，行和 = [0.976, 1.024] ✗（更近了）

第 2 轮：
  行归一化 → [[0.4483, 0.5517], [0.5493, 0.4507]]  行和 = 1 ✓，列和 = [0.998, 1.002]
  列归一化 → [[0.4494, 0.5504], [0.5506, 0.4496]]  列和 = 1 ✓，行和 = [0.9998, 1.0002] ✓

极限 ≈ [[0.4495, 0.5505], [0.5505, 0.4495]] —— 两轮即收敛到 10⁻⁴ 量级

2×2 Sinkhorn 两轮迭代演示（作者补充，论文未含此例）。首轮「对 exp 矩阵做行归一化」正是 §3.3 kernel 里减行最大值的 softmax 的数学等价。收敛速度取决于矩阵病态程度——\(\tilde H^{res}\) 逐 token 变化、无法保证良性条件，这与 §4.1「20 次迭代未完全收敛、复合增益残差 ~1.6」的观察一致（推断）。

同一算法最广为人知的应用在别处：熵正则化最优传输（Cuturi 2013）用它把代价矩阵迭代成合法传输计划。mHC 借它当流形投影用，实验取 \(t_{max}=20\) 次作为精度/开销折衷。

梯度如何穿过投影回传

投影全程只含 exp 与除法，均为可微操作——整条链 \(\tilde H^{res} \to \exp \to 20\) 次归一化 \(\to H^{res}\) 对 \(\tilde H^{res}\) 可微，autograd 穿过 20 次迭代把梯度送回 \(\varphi^{res}\)。所以 Sinkhorn 不是「训练时加惩罚、部署时才合法」的事后补救，而是端到端可训练的严格参数化：混合策略照常学习，稳定性由前向计算的结构保证。代价是反向需要 20 次迭代的中间量——§2.3 的自定义反向 kernel（片上重算再遍历迭代）就是为它服务的。

图 2｜mHC 单层数据流（对应官方实现 Block.forward）。系数支路把 n×d 流矩阵展平后与融合的投影矩阵 \(\varphi\) 做 matmul，除以 RMS 范数挪到 matmul 之后（数学等价，省一次大张量读写），产出 24 个原始系数；按语义拆成 pre（σ）、post（2σ）、comb（Sinkhorn ×20）三组。层输入 = pre 加权聚合的 d 维向量；层输出经 post 写回，与 comb 混合的原始流相加得到下一代流矩阵。

图 3｜hc_pre / hc_post 全步骤数据流（对应 kernel.py 的 hc_split_sinkhorn_kernel 与 model.py 的 Block.hc_pre / hc_post）。上带系数生成：流矩阵展平（①）→ 整体 RMS 统计（②）→ matmul φ 得 24 维（③）→ 后置除以 RMS（④，§4.3.1 等价重排）；24 维按序拆成 pre / post / comb 三段，各分支先施加 α·(·)+b，再分别经 σ+ε（读出权重）、2σ（写回权重）、Sinkhorn×20（双随机混合矩阵）变换（⑤–⑦）。中带层计算：原始流按 pre 加权和读出层输入（⑧），经 RMSNorm 与层 F 得 d 维输出（⑨）。下带流更新：comb 对 4 条流做凸组合混合（⑩）、post 把层输出广播写回（⑪）、相加得新一代流矩阵（⑫）进入下一子层。

2.3 工程设计：把 6.7% 开销磨出来（论文 §4.3）

mHC 论文一半篇幅在工程上，三条主线：

  • Kernel 融合：RMSNorm 的除法重排到 matmul 之后（数学等价）；用 TileLang 编写混合精度 kernel（\(\varphi\) 用 tf32、激活 bf16、系数 fp32）；Sinkhorn 迭代整体在单 kernel 内完成，反向用自定义 kernel 在片上重算中间结果再遍历迭代；\(H^{post}\) 写回 + \(H^{res}\) 混合 + 残差合并融合为一个 kernel，读从 \((3n{+}1)C\) 降到 \((n{+}1)C\)、写从 \(3nC\) 降到 \(nC\)；
  • 选择性重算：每 \(L_r\) 层只持久保存块首输入 \(x_{l_0}\)（\(\approx nC\)/token）与层函数输出，块内重算流状态与归一化输入；峰值显存由 \(nC\cdot\lceil L/L_r\rceil + (n{+}2)C\cdot L_r\) 决定，最优块大小 \(L^*_r = \sqrt{nL/(n{+}2)}\)——实测恰与流水线 stage 层数对齐，于是重算边界直接对齐流水线；
  • DualPipe 通信重叠扩展：n 流使流水线 stage 边界通信量翻 n 倍；把 MLP 的 \(F_{post,res}\) kernel 放到高优先级计算流避免阻塞通信，attention 不用 persistent kernel 以便可被抢占，重算与流水线通信解耦（stage 首激活已在本地缓存）。

综合效果：n=4 的大规模训练仅 +6.7% 墙钟开销（论文摘要；V4 论文 §3.4.2 口径为「1F1B 流水线 stage 的 6.7%」）。

3.2 Block：hc_pre / hc_post 与公式的逐行对应

class Block(nn.Module):
    """Transformer block with Hyper-Connections (HC) mixing.
    Instead of a simple residual, HC maintains `hc_mult` copies of the hidden state.
    hc_pre: reduces hc copies -> 1 via learned weighted sum (pre-weights from Sinkhorn).
    hc_post: expands 1 -> hc copies via learned post-weights + combination matrix."""
    def __init__(self, layer_id: int, args: ModelArgs):
        ...
        self.hc_mult = hc_mult = args.hc_mult
        mix_hc = (2 + hc_mult) * hc_mult        # n + n + n² = 24 个系数
        hc_dim = hc_mult * args.dim
        with set_dtype(torch.float32):
            self.hc_attn_fn = nn.Parameter(torch.empty(mix_hc, hc_dim))   # φ（三组合一，含 RMSNorm 权重）
            self.hc_ffn_fn = nn.Parameter(torch.empty(mix_hc, hc_dim))
            self.hc_attn_base = nn.Parameter(torch.empty(mix_hc))         # 静态 bias b
            self.hc_ffn_base = nn.Parameter(torch.empty(mix_hc))
            self.hc_attn_scale = nn.Parameter(torch.empty(3))             # α_pre/α_post/α_res 门控
            self.hc_ffn_scale = nn.Parameter(torch.empty(3))

    def hc_pre(self, x: torch.Tensor, hc_fn, hc_scale, hc_base):
        # x: [b,s,hc,d] -> 层输入 y: [b,s,d]，同时产出 post/comb 供 hc_post 使用
        shape, dtype = x.size(), x.dtype
        x = x.flatten(2).float()                                  # vec(X)：n×d → 1×n·d
        rsqrt = torch.rsqrt(x.square().mean(-1, keepdim=True) + self.norm_eps)
        mixes = F.linear(x, hc_fn) * rsqrt                        # 先 matmul 再除 RMS（论文 §4.3.1 等价重排）
        pre, post, comb = hc_split_sinkhorn(mixes, hc_scale, hc_base, self.hc_mult, self.hc_sinkhorn_iters, self.hc_eps)
        y = torch.sum(pre.unsqueeze(-1) * x.view(shape), dim=2)   # 层输入 = Σ_k pre[k]·X[k]
        return y.to(dtype), post, comb

    def hc_post(self, x: torch.Tensor, residual: torch.Tensor, post, comb):
        # x: [b,s,d], residual: [b,s,hc,d] -> X_{l+1} = comb·X_l + post ⊗ x
        y = post.unsqueeze(-1) * x.unsqueeze(-2) + torch.sum(comb.unsqueeze(-1) * residual.unsqueeze(-2), dim=2)
        return y.type_as(x)

    def forward(self, x: torch.Tensor, start_pos: int, input_ids):
        residual = x
        x, post, comb = self.hc_pre(x, self.hc_attn_fn, self.hc_attn_scale, self.hc_attn_base)
        x = self.attn_norm(x)
        x = self.attn(x, start_pos)
        x = self.hc_post(x, residual, post, comb)                 # attention 子层后更新流

        residual = x
        x, post, comb = self.hc_pre(x, self.hc_ffn_fn, self.hc_ffn_scale, self.hc_ffn_base)
        x = self.ffn_norm(x)
        x = self.ffn(x, input_ids)
        x = self.hc_post(x, residual, post, comb)                 # MoE 子层后再次更新流
        return x

摘自 inference/model.py:647-700（有删节）。对照要点：每层内 attention 与 MoE 各做一次完整的 mHC 更新（即论文 Fig 3 把一个 block 拆成两层计数的口径）；\(\varphi\) 把三组投影折叠成单个 \([24, n\cdot d]\) 矩阵（attention/FFN 各一份），RMSNorm 权重按论文说法「absorbed in \(\varphi\)」；F.linear(...) * rsqrt 正是论文 §4.3.1 的「除以范数后置」等价重排；hc_post 一行完成式 (3) 的 \(B X + C\otimes F\) 两个乘加。

3.3 hc_split_sinkhorn：约束三分支的 TileLang 内核

def hc_split_sinkhorn_kernel(hc: int, sinkhorn_iters: int, eps: float):
    n = T.symbolic("n")
    mix_hc = (2 + hc) * hc          # 24

    @T.prim_func
    def hc_split_sinkhorn_kernel_(
        mixes: T.Tensor[(n, mix_hc), FP32],      # 原始动态+静态融合系数
        hc_scale: T.Tensor[(3,), FP32],
        hc_base: T.Tensor[(mix_hc,), FP32],
        pre: T.Tensor[(n, hc), FP32],            # Hpre（读出）
        post: T.Tensor[(n, hc), FP32],           # Hpost（写回）
        comb: T.Tensor[(n, hc, hc), FP32],       # Hres（流内混合）
    ):
        with T.Kernel(n, threads=threads) as i:
            mixes_shared = T.alloc_shared(mix_hc, FP32)
            comb_frag = T.alloc_fragment((hc, hc), FP32)
            T.copy(mixes[i, :], mixes_shared)

            for j in T.Parallel(hc):
                pre[i, j] = T.sigmoid(mixes_shared[j] * hc_scale[0] + hc_base[j]) + eps
            for j in T.Parallel(hc):
                post[i, j] = 2 * T.sigmoid(mixes_shared[j + hc] * hc_scale[1] + hc_base[j + hc])
            for j, k in T.Parallel(hc, hc):
                comb_frag[j, k] = mixes_shared[j * hc + k + hc * 2] * hc_scale[2] + hc_base[j * hc + k + hc * 2]

            # 第一轮：行 softmax（带 max 减除的数值稳定 exp+行归一化）
            row_max = T.alloc_fragment(hc, FP32)
            T.reduce_max(comb_frag, row_max, dim=1)
            for j, k in T.Parallel(hc, hc):
                comb_frag[j, k] = T.exp(comb_frag[j, k] - row_max[j])
            T.reduce_sum(comb_frag, row_sum, dim=1)
            for j, k in T.Parallel(hc, hc):
                comb_frag[j, k] = comb_frag[j, k] / row_sum[j] + eps
            # 列归一化
            T.reduce_sum(comb_frag, col_sum, dim=0)
            for j, k in T.Parallel(hc, hc):
                comb_frag[j, k] = comb_frag[j, k] / (col_sum[k] + eps)

            for _ in T.serial(sinkhorn_iters - 1):        # 共 20 轮行/列交替归一化
                T.reduce_sum(comb_frag, row_sum, dim=1)
                for j, k in T.Parallel(hc, hc):
                    comb_frag[j, k] = comb_frag[j, k] / (row_sum[j] + eps)
                T.reduce_sum(comb_frag, col_sum, dim=0)
                for j, k in T.Parallel(hc, hc):
                    comb_frag[j, k] = comb_frag[j, k] / (col_sum[k] + eps)

            T.copy(comb_frag, comb[i, :, :])
    return hc_split_sinkhorn_kernel_

摘自 inference/kernel.py:372-427（TileLang DSL，有删节；Python 包装 hc_split_sinkhorn 在 kernel.py:430-439）。24 个系数在前 24 维连续排布：前 n 个给 pre、中间 n 个给 post、后 n² 个给 comb；三组分别套 σ、2σ、Sinkhorn。整个投影逐 token（kernel 网格即 token 维）在单 kernel 内完成，与论文 §4.3.1「Sinkhorn 迭代在单个 kernel 内实现」对应。

① 代码首轮用「减行最大值的 softmax」替代论文所述 \(\exp\) 后行归一化——数学上等价（softmax = exp 归一化），只是数值稳定的实现变体；② 每次归一化后加 eps=1e-6 防止零元素，属实现细节，论文未提及；③ 20 轮迭代 = 首轮 softmax+列归一化 + 后续 19 轮（行、列），与 \(t_{max}=20\) 对应。

5. 在 DeepSeek 产品线的落地

5.1 DeepSeek-V4：1.6T 生产模型中的 mHC

V4 系列把 mHC 列为三大架构升级之一（另两项：CSA/HCA 混合注意力、Muon 优化器）。V4 论文 §2.2 完整复述了 mHC 设计（记号改为 \(A_l/B_l/C_l\)），配置与 mHC 论文一致（\(n_{hc}=4\)、\(t_{max}=20\)）。几个值得注意的生产细节：

  • 优化器分工（§2.4）：mHC 的静态 bias 与门控因子（代码中的 hc_*_base / hc_*_scale）用 AdamW 优化，其余矩阵参数用 Muon——标量/近标量参数不参与 Newton-Schulz 正交化；
  • 训练框架（§3.4.2）：融合 kernel（训练+推理）+ 选择性重算（重算层间隐状态与归一化输入、不重算计算密集操作）+ DualPipe 调整，把 mHC 墙钟开销压到 1F1B stage 的 6.7%；
  • 确定性（§3.3）：mHC 的 matmul 输出维度只有 24，小批量下需要 split-k，通过「分片输出 + 后续确定性规约」避免原子加导致的非确定累积。

5.2 DeepSeek-V4.1：Single-Pass mHC 与 Mega-mHC

V4.1 把 mHC 的显存流量砍半（§2.4.1）。推理实现的理想下界是每 token 读 \((n{+}1)d\)、写 \((n{+}1)d\)（合计 \((2n{+}2)d\)），但 V4 的多 pass 实现因数据依赖拆成三个串行 kernel，实际流量 \((4n{+}4)d\)——恰为下界两倍：

实现激活流量（每 token）说明
V4 多 pass（3 kernel 串行）\((4n{+}4)d\) = 2× 下界残差更新 → 系数计算 → 输入混合，各自读写一遍流
两 pass（折叠后）\((3n{+}2)d\)残差更新与系数计算共享一次流遍历；输入混合仍需第二次读 \(X_l\)
Single-Pass + Mega-mHC\((2n{+}2)d\) = 达到下界单 kernel 读一次写一次，激活流量较原实现减半

表 6｜V4.1 论文 §2.4.1 的 kernel 流量对比（n=4 时：20d → 14d → 10d）。

关键改动很小：把输入混合系数错开一层——第 l 层用第 l−1 层生成的 \(A_{l-1}\) 而非 \(A_l\) 做输入混合：

\[ X_{l+1} = B_l X_l + C_l\, F_l(A_{l-1} X_l),\qquad (A_l, B_l, C_l) = H(X_l) \]

输入混合不再依赖本层刚算出的系数，「每个 tile 的 \(X_l\) 可同时用于输入混合与系数预测」，三步融合成单个 Mega-mHC kernel（含输入 pre-norm 与 FP8 转换，部署于 DeepGEMM）。错开一层带来一步的系数时延，实测性能损失可忽略；训练侧保留原多 kernel 实现（错位只改变各层应用哪份系数），部署侧才启用单 kernel。配置不变：扩展率 4、Sinkhorn 20 迭代；45T token 多模态训练全程无不稳定。

图 4｜mHC 激活显存流量演进（n=4，V4.1 论文 §2.4.1 口径）。Single-Pass 用「系数错开一层」消除 kernel 间数据依赖，使单融合 kernel 达到理论下界、流量较 V4 实现减半。

6. 事实与推断的边界

  • 论文/源码证实：所有公式、理论性质（非扩张、封闭性、Birkhoff 几何）、实验数字（增益 3000→1.6、loss −0.021、表 5 基准、6.7% 开销、\(L^*_r\) 公式）出自 paper/mhc.pdf；V4/V4.1 落地细节出自 paper/deepseek_v4.pdf（§2.2、§2.4、§3.3、§3.4.2）与 paper/deepseek_v41.pdf（§2.4.1、§4.2.1-4.2.2）；代码片段与行号来自 /tmp/paper-research/v4-pro/inference/ 实际克隆内容（commit b5968e9，2026-09-14 抓取；model.py、kernel.py、config.json）。
  • 推断（已标注）：① §3.3 推断框中「首轮 softmax 是 exp+行归一化的数值稳定等价」「eps 为实现细节」；② hc_head 无需混合约束的解读；③ 表 2 中 n=4 的量级换算（21C/13C）；④ §2.2 新增的「出口投影」设计动机分析与 2×2 Sinkhorn 数值演示（演示为作者补充，论文未含此例；「收敛速度与矩阵病态程度相关」为解释性推断）。
  • 未决：① mHC 论文的 6.7% 与稳定性实验均为 DeepSeek in-house 规模，公开实验只到 27B/262B tokens，更大规模的对照数据未公开；② \(H^{pre}/H^{post}\) 的 σ/2σ 约束不保证读出/写入通道严格守恒（论文只论证了 \(H^{res}\) 的守恒性），稳定性保证是不完整的；③ 论文未提供 \(t_{max}\) 的敏感性消融（20 次的选取依据仅为「practical value」）。

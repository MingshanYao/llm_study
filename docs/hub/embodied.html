具身智能与 VLA

零基础主线 · 从机器人学习基础到主流 VLA 架构（RT-2 / OpenVLA / π0 / Helix / GR00T），落到实战与成长路线图

推荐阅读路线

1

第 0 讲 · 全景图

具身智能是什么、和 ChatGPT 有什么区别、为什么难；VLA 发展时间线（SayCan → RT-1 → RT-2 → OpenVLA/π0 → Helix/GR00T）、分类坐标轴、全景表与术语表。零数学，只搭全景、定地图。

2

第 1 讲 · 机器人学习基础

机器人怎么被表示（关节空间 vs 任务空间、控制频率）、怎么学会（行为克隆 vs 强化学习、covariate shift）；ACT 动作分块精读、遥操作数据采集与「数据金字塔」、Open X-Embodiment 与 sim2real。

3

第 2 讲 · RT-1 与 RT-2

VLA 的诞生：RT-1 用 Transformer + 13 万真机数据吃下 700+ 任务；RT-2 把动作写成文本 token 让 VLM 直接输出，co-fine-tuning 带来语义泛化与涌现能力——「动作 = token」是读懂一切 VLA 的钥匙。

4

第 3 讲 · OpenVLA

最有影响力的开源 VLA：Llama 2 7B + DINOv2/SigLIP 融合视觉编码器，OXE 970k 轨迹训练；LoRA 单卡微调实操、OpenVLA-OFT 的并行解码与连续动作改造，以及开源生态一览。

5

第 4 讲 · Diffusion Policy 与 π0

连续动作头主线：离散 token 的三宗罪、扩散模型与 flow matching 十分钟速成（公式全部配大白话）、Diffusion Policy 与 π0/π0.5/FAST 精读，以及五条动作头路线的对比表。全系列数学最多的一讲，可先跳过后面回补。

6

第 5 讲 · 2025–2026 前沿全景

Figure Helix、NVIDIA GR00T N1、Google Gemini Robotics 三大路线深讲（双系统：慢想 VLM + 快动策略），国内 GO-1/RDT-1B/WALL-OSS 等概览，世界模型如何为 VLA 造数据、当考官，以及七大技术趋势。

7

第 6 讲 · 实战与成长路线图

零硬件也能动手：LeRobot/openpi/Isaac GR00T 软件栈、LIBERO/SimplerEnv 仿真基准、四个由浅入深的动手项目（跑通 ACT → LoRA 微调 OpenVLA → 复现 π0 微调 → 自采数据），微调工程要点清单与四阶段成长路线。

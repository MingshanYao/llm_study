RL 训练工程师零基础七讲 · 第 3 讲：PPO 精讲

0 全景图 1 策略梯度 2 LLM×RL 3 PPO 4 RLHF·DPO 5 RLVR·GRPO 6 系统与实战 番外 SC

本讲定位：RLHF 时代的引擎（InstructGPT / 早期 ChatGPT 用它做对齐）。第 5 讲的 GRPO 是它的「瘦身版」，所以本讲也是 GRPO 的前置。

前置要求：第 1 讲（REINFORCE、优势）、第 2 讲（轨迹 log 概率、KL 缰绳、reference model）。本讲新数学只有三小块，全部配手算。

难点预警：clip 的分支行为和 GAE 的递推是全系列最容易懵的两处——本讲用「逐格手算的表格」代替推导，跟着表格走一遍就通。

本讲目标：REINFORCE 有两大浪费——数据用一次就扔（LLM 生成很贵）、功劳记账太粗（整条链同乘一个奖励）。PPO 用三件发明补齐：① 重要性采样：给旧数据乘一个修正比率，回收再用；② clip：给每次更新装保险丝，新旧策略不许差太多；③ GAE：借一个「预期得分」网络，把末尾奖励精细拆分到每个 token。最后看全 PPO 在 LLM 上的完整形态——四个模型同时在场的架构，以及它为什么难跑：这段「难」正是第 5 讲 GRPO 出场的原因。

1. REINFORCE 的两个浪费

第 2 讲末尾的训练循环能跑，但有隐情。rollout 一批回答的成本极高（几百条 × 几百 token 的推理），而这批数据在 一次参数更新之后就「过期」了——因为策略变了，理论上梯度估计不再指向正确方向，数据只能扔掉重采。第二个浪费来自记账：优势 = 整条链共用一个 \(R - b\)，第 2 讲的功劳记账难题原封未动。

PPO（Proximal Policy Optimization，OpenAI 2017）直击这两点，外加把 KL 缰绳整合进来。它在 LLM 出现前就是机器人、游戏里的主力算法，InstructGPT 把它带进 LLM 后训练，成了 RLHF 的代名词。拆开看只有三个零件。

2. 零件一：重要性采样——让旧数据能复用

问题：梯度估计是「按新策略的概率加权」的期望，但数据是旧策略采的，分布对不上。恒等变形修正一下——分子分母同乘比率：

\[ \mathbb{E}_{\pi}\big[f(x)\big] = \mathbb{E}_{\pi_{\mathrm{old}}}\Big[\underbrace{\frac{\pi(x)}{\pi_{\mathrm{old}}(x)}}_{\rho\ \text{重要性比率}} f(x)\Big] \]

直觉：旧数据里，凡是「新策略比旧策略更看重」的样本，加权系数 \(\rho > 1\) 放大它的声音；「更不看重的」\(\rho < 1\) 缩水。比如某回答在旧策略里概率 0.2、新策略里 0.4，则 \(\rho = 2\)——它按双倍计入估计。

LLM 场景里 \(\rho\) 是逐 token 的：\(\rho_t = \pi_{\theta}(\text{token}_t)/\pi_{\mathrm{old}}(\text{token}_t) = \exp(\log\pi_{\theta} - \log\pi_{\mathrm{old}})\)。工程上毫无负担——rollout 时推理引擎本来就要输出旧策略的 log 概率，存下来即可。

直觉重要性采样像「加权重放」：把旧时代的采访录音（旧数据）剪进新节目，凡是立场变了的片段按变化幅度调音量。代价也在这里：一旦新旧立场差太远（\(\rho\) 巨大或极小），个别片段的音量会大得离谱——方差爆炸。所以它必须搭配下一节的保险丝。

3. 零件二：clip——每次更新的保险丝

先把梯度估计改写成「直接可优化」的目标函数（用优势 \(A\) 替换 \(R\)，用比率替换权重）：

\[ L(\theta) = \mathbb{E}\big[\,\rho(\theta)\, A\,\big], \qquad \rho = \frac{\pi_\theta}{\pi_{\mathrm{old}}} \]

如果放着不管，优化器会找到把 \(\rho\) 推到天上的解（尤其优势为正时），一头撞进重要性采样失效的区域。PPO 的做法粗暴而有效——把 \(\rho\) 摁在 \([1-\varepsilon,\ 1+\varepsilon]\) 区间里（典型 \(\varepsilon = 0.2\)），并取两支里更保守的那个：

\[ L^{\mathrm{CLIP}}(\theta) = \mathbb{E}\Big[\min\big(\rho A,\ \mathrm{clip}(\rho,\ 1-\varepsilon,\ 1+\varepsilon)\cdot A\big)\Big] \]

公式看着唬人，行为用表格一遍算清。\(\varepsilon = 0.2\)，分「好动作 \(A=+2\)」和「坏动作 \(A=-2\)」两组，各取三个 \(\rho\)：

场景\(\rho\)未裁剪 \(\rho A\)裁剪项 \(\mathrm{clip}(\rho)\cdot A\)\(\min\)（实际目标）效果
好动作
\(A=+2\)		0.81.6\(0.8\times2=1.6\)1.6没截断：概率还没涨够，继续推 ↑
1.12.2\(1.1\times2=2.2\)2.2没截断：仍在区间内，继续推 ↑
1.53.0\(\mathbf{1.2}\times2=2.4\)2.4截断：涨过 \(1{+}\varepsilon\)，目标变平，不再推 ↑
坏动作
\(A=-2\)		0.5−1.0\(\mathbf{0.8}\times({-}2)=-1.6\)−1.6截断：压过 \(1{-}\varepsilon\)，目标变平，不再压 ↓

读表三要点：

  1. 对称的是「更新量」，不是「行为」：正优势时，概率涨过 \(1+\varepsilon\) 就停手（别得意忘形）；负优势时，概率压过 \(1-\varepsilon\) 就停手（别赶尽杀绝）。
  2. 单向的不对称：坏动作如果概率不降反升（\(\rho > 1+\varepsilon\)），不会被拦——min 取到真实的 \(\rho A\)，惩罚照常且更大。保险丝只防「学过头」，不防「纠错」。
  3. clip 不是裁剪梯度，是压平目标：截断区内目标函数对 \(\rho\) 的斜率为 0，梯度自然消失。常见误解是把 clip 想象成「把梯度砍断」，机制其实是「目标函数在这里躺平」。
为什么取 minmin 永远选中「对优化者更不利」的那一支——悲观主义下界。宁可少学，绝不多学：这是 PPO 名字里 Proximal（近端/保守）的含义——每次更新只许在旧策略附近挪一小步。上一节重要性采样的方差爆炸，被这根保险丝兜住了。

4. 零件三：GAE——把末尾奖励拆到每个 token

4.1 先请出 critic（价值网络）

第 1 讲的 baseline 是「平均分」这一刀切。PPO 请来一位专门的记账员：价值网络 \(V(s)\)（术语 critic），输入当前状态（LLM 场景 = 当前前缀），输出「从这里出发、按当前策略走下去，预期最终得多少分」。它和策略网络一起训练，学习目标就是「预测得更准」（回归到实际发生的回报）。

有了 \(V\)，「这一步走得好不好」就有了一个精细的定义——TD 残差（Temporal Difference error）：

\[ \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) \]

读法：「实际得到的（这一步的即时奖励 + 下一状态的预期值）减去出发前的预期」。为正 = 这步走得比预期好，为负 = 比预期差。\(\gamma \in [0,1]\) 是折扣因子（对未来奖励打多少折，LLM 场景通常取接近 1）。

4.2 GAE：δ 的加权平均

单步的 \(\delta_t\) 只看眼前一步，噪声大；一路加到底（蒙特卡洛）又太抖。GAE（Generalized Advantage Estimation）用指数衰减把多步 \(\delta\) 揉在一起：

\[ A_t = \delta_t + (\gamma\lambda)\,\delta_{t+1} + (\gamma\lambda)^2\,\delta_{t+2} + \cdots \]

\(\lambda \in [0,1]\) 是方差-偏差的调节旋钮：\(\lambda = 0\) 只信眼前（\(A_t = \delta_t\)，方差小、偏差大）；\(\lambda = 1\) 全部加总，恰好等于「实际总回报 − 出发时预期」\(R - V(s_t)\)（无偏、方差大）。LLM 训练里 \(\gamma\) 常取 1.0、\(\lambda\) 取 0.95~1.0。

4.3 完整手算

设一条 3-token 的回答，每步即时奖励 \(r = [0,\ 0,\ 1]\)（答对末尾 +1；若接 KL 罚款，前两步会是小负数），critic 的预期 \(V = [0.2,\ 0.5,\ 0.3]\)（末尾之后 \(V = 0\)）。取 \(\gamma = 1\)，\(\lambda = 0.5\)：

步骤算式结果
\(\delta_1 = r_1 + V_2 - V_1\)\(0 + 0.5 - 0.2\)\(+0.3\)
\(\delta_2 = r_2 + V_3 - V_2\)\(0 + 0.3 - 0.5\)\(-0.2\)
\(\delta_3 = r_3 + 0 - V_3\)\(1 - 0.3\)\(+0.7\)
\(A_3 = \delta_3\)末步无后续\(0.7\)
\(A_2 = \delta_2 + \lambda\delta_3\)\(-0.2 + 0.5\times0.7\)\(+0.15\)
\(A_1 = \delta_1 + \lambda A_2\)\(0.3 + 0.5\times0.15\)\(+0.375\)

对照两个极端感受 \(\lambda\) 的作用：\(\lambda = 0\)（只看眼前）给 \(A = [0.3,\ -0.2,\ 0.7]\)——第二步被 critic 的一次坏预测（\(V_2 = 0.5\) 偏高）拖成负值；\(\lambda = 1\)（蒙特卡洛）给 \(A = R - V = [0.8,\ 0.5,\ 0.7]\)。GAE（0.375, 0.15, 0.7）是两者的折中：单步噪声被前后步稀释，但整体仍指向「这条链比预期好」。

注意 \(V\) 的预测质量直接决定 \(\delta\) 的质量——critic 训不好，优势就是噪声。LLM 场景里 critic 与 policy 一样大、一样难训，这是 PPO 工程负担的主要来源之一，记住它，第 5 讲 GRPO 的第一刀就砍在这里。

5. 拼装：PPO 的 loss 与四模型架构

PPO 的总 loss 由三部分组成：

\[ \mathcal{L} = \underbrace{\mathcal{L}^{\mathrm{CLIP}}}_{\text{策略（本讲第 3 节）}} \; - c_1\, \underbrace{\mathcal{L}^{V}}_{\text{critic 的 MSE}} \; - c_2\, \underbrace{H(\pi)}_{\text{熵奖励（可选）}} \]

熵奖励 \(H\) 惩罚「分布过尖」——维持探索（第 2 讲温度一节的精神续集），LLM 训练里常不加或加得很小。第 4、5 讲的算法都是对第一项动手术。

而在 LLM-RLHF 实现里，一次训练要同时养着四个模型——这是 PPO 时代最著名的架构图：

模型别称干什么训练吗
Actor（策略）\(\pi_\theta\)生成回答，被 clip 目标更新✅ 训练
Critic（价值）\(V(s)\)预测预期得分，供 GAE 记账✅ 训练
Reference（参考）\(\pi_{\mathrm{ref}}\)（= SFT 模型）算逐 token KL 罚款（第 2 讲的缰绳）❄️ 冻结
Reward Model（奖励）RM给整条回答打分（RLHF 路线）❄️ 冻结

四个模型全是几十亿参数级：两个在训练（各带优化器状态和梯度）、两个在旁听（占推理显存），再加 rollout 引擎本身——这就是「RLHF 训练贵、难、脆」的物质基础。第 6 讲的系统架构整页都在回答「这些东西怎么塞进机房」；第 5 讲的 GRPO 则直接砍掉其中最贵的一件（critic）。

6. 为什么 LLM + PPO 难跑

把 2023 年前后各家实践中的抱怨归纳成四条（它们就是后续算法演化的路线图）：

痛点具体表现后来的解法
rollout 太贵生成占训练时间的 50%~80%，且 on-policy 数据用一次就扔重要性采样 + 多 epoch 复用（本讲）；更激进的异步架构（第 6 讲）
critic 不好训价值网络和策略一样大，预测长链条回报困难，训练不稳GRPO 用组内对比替代 critic（第 5 讲）
超参敏感\(\beta, \varepsilon, \lambda, \gamma\), lr, KL 目标值……任何一处不对都表现为「reward 不涨」或「模型变傻」DPO 绕开 RL 循环（第 4 讲）；DAPO 等对超参做鲁棒化（第 5 讲）
RM 被 hack训练后期 reward 涨、人工评测跌——模型学会了刷 RM 的分RLVR 用程序判分替代 RM（第 5 讲）；KL 缰绳加强

所以后来的故事并不是「PPO 被淘汰」：它的三个零件全部存活——clip 成了几乎所有现代算法的标配，重要性采样以 ratio 的形式无处不在，GAE 的「优势」概念是通用语言。被淘汰的只是「critic + 四模型」的重装形态。

7. 自查清单

下面 8 个问题都能不假思索地回答，就可以进入第 4 讲：

  1. REINFORCE 的两个浪费是什么？（答：数据用一次就扔；整条链同乘一个奖励、记账粗）
  2. 重要性采样的修正是哪个量、直觉是什么？（答：比率 \(\rho = \pi/\pi_{\mathrm{old}}\)；新策略更看重的旧样本加权放大）
  3. \(\rho\) 偏离 1 太远会怎样？（答：估计方差爆炸——重要性采样失效区，所以要 clip）
  4. clip 的行为：A>0 与 A<0 各在哪儿刹车？哪一侧不设防？（答：涨过 \(1{+}\varepsilon\) 停、压过 \(1{-}\varepsilon\) 停；坏动作概率升高不设防、照罚）
  5. clip 的机制是砍梯度吗？（答：不是，是让目标函数在截断区变平，梯度随之消失）
  6. TD 残差 \(\delta_t\) 的读法？（答：这一步的实际所得 − 出发前的预期，正=比预期好）
  7. GAE 的 \(\lambda = 0\) 和 \(\lambda = 1\) 各退化为？手算例子的 \(A_2\) 是多少？（答：\(A_t=\delta_t\)；\(A_t = R - V(s_t)\)；0.15）
  8. 四个模型分别是什么、哪两个在训练？（答：actor / critic 训练，reference / reward model 冻结）

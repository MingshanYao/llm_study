系列：大模型量化零基础七讲（本篇为第 1 讲）

前置：第 0 讲的三个词——位宽、浮点数三段、有损压缩。本讲需要的数学只有四则运算和四舍五入，所有公式都会配手算例子。

本讲地位：scale / zero-point / 对称非对称 / 粒度 / 误差 / 校准——这六个词是整个量化领域的「普通话」，后面五讲的所有算法都在用它们说话。

本讲目标：把第 0 讲的「就近入座」变成能写能算的公式。① 量化和反量化的通用公式——只涉及一个缩放系数 \(s\)、一个偏移 \(z\) 和四舍五入；② 对称 / 非对称两种格子怎么选；③ per-tensor / per-channel / per-group 粒度谱系——4-bit 模型的标配是哪一档；④ 量化误差的两种来源（舍入、裁剪）及其权衡；⑤ scale 怎么定——四种校准准则。最后手算一个完整例子：把 6 个真实权重量到 INT4 再还原。

1. 量化公式：一次仿射变换

先把场景说小：给你一堆真实值（比如某个权重矩阵里的数），要存成 \(b\) 位整数。\(b=4\) 时只有 0~15 共 16 个格子可用。怎么把「真值」和「格子编号」对应起来？

一个生活原型：摄氏度和华氏度的换算 \(F = 1.8C + 32\)。两个刻度不同的温度轴，靠「乘一个系数、加一个偏移」互转——数学上叫仿射变换（affine transform）。量化做的正是这件事：把「真值轴」映射到「整数轴」。

\[ q = \mathrm{clip}\big(\mathrm{round}(x / s) + z,\; 0,\; 2^b - 1\big) \] \[ \hat{x} = s \cdot (q - z) \]

两个公式、三个新符号，逐个拆：

  • \(s\)（scale，缩放系数）：一个格子代表多大的真值。\(s\) 越小，格子越细密，精度越高。它是个小数，用量化后的数据一起保存。
  • \(z\)（zero-point，零点）：真值 0 对应第几号格子。它的作用是让「0 这个特殊的数」能被精确表示——神经网络里 0 无处不在（padding、ReLU 输出），0 量化错了会连环出错。
  • \(\mathrm{round}\)：四舍五入到最近整数——「就近入座」。\(\mathrm{clip}\)：超出 0~\(2^b-1\) 的强制压回边界（防止溢出）。
  • \(\hat{x}\)：反量化恢复出来的值。注意 \( \hat{x} \neq x \)——差的那一点就是量化误差。
手算设 \(s=0.1\)、\(z=8\)（16 个格子覆盖真值区间 \([-0.8,\, 0.7]\)）。权重 \(x = 0.7843\)：
量化：\(\mathrm{round}(0.7843/0.1) = \mathrm{round}(7.843) = 8\)，\(q = 8 + 8 = 16\)——超出 15，clip 到 15。
反量化：\(\hat{x} = 0.1 \times (15 - 8) = 0.7\)。误差 0.0843，而且主要来自裁剪（超出区间被砍），不是舍入。

存盘时，整个矩阵只存两样东西：整数矩阵 \(q\)（每数 4 位）和一小撮 \((s, z)\)。给谁配一对 \((s,z)\)，就是下一节的「粒度」；\((s,z)\) 具体取多少，就是第 4、5 节的「误差与校准」。

2. 对称 vs 非对称：格子怎么摆

2.1 对称量化：0 居中

让真值 0 精确落在格子区间正中央（\(z\) 固定在 \(2^{b-1}\)），区间取 \([-s \cdot 2^{b-1},\, +s \cdot 2^{b-1}]\)，公式简化为：

\[ q = \mathrm{clip}\big(\mathrm{round}(x/s),\, -2^{b-1},\, 2^{b-1}-1\big), \qquad \hat{x} = s \cdot q \]

好处：公式少一个减法，kernel 跑得快；0 精确无误。代价：如果数据其实全在正半轴（比如某层激活都 > 0），负半轴的格子全浪费。

2.2 非对称量化：区间贴着数据走

让 16 个格子贴着数据的实际范围 \([\min, \max]\) 铺开：

\[ s = \frac{\max - \min}{2^b - 1}, \qquad z = \mathrm{round}\!\left(-\frac{\min}{s}\right) \]

好处：一个格子都不浪费，同样的位宽下误差更小。代价：多存一个 \(z\)、计算多一步。一个直观对比：数据全在 \([0,\, 2]\) 时，对称量化只能把区间定在 \([-2, 2]\)——一半格子白给；非对称量化正好铺满 \([0, 2]\)。

对称（symmetric）非对称（asymmetric）
格子布局关于 0 对称，负正各半贴着 \([\min, \max]\)，0 不一定居中
公式\(\hat{x} = s \cdot q\)，无需 \(z\)\(\hat{x} = s(q-z)\)，多一步减法
适合权重（分布近似关于 0 对称）激活（分布常偏一侧、有正无负）
常见于GPTQ、AWQ 的权重（INT4/INT8）激活量化、端侧 INT8 部署
记忆权重像「身高误差表」——正负都有、以 0 为中心，对称格子刚好；激活像「年龄分布」——全在正半轴，硬用对称格子等于扔掉一半格子。实际系统经常两者混用：权重对称、激活非对称。

图 1-1｜非对称量化的映射全景。注意两个细节：① 真值 0 精确落在 \(z=8\) 号格——这就是 zero-point 存在的意义；② 真实分布又窄又挤（第 0 讲的底牌一），0.95 这样的离群点才会撞上边界。

3. 粒度：给谁配一对 (s, z)

公式里的 \((s, z)\) 不是全模型共用一对——「给谁配一对」决定了量化的粒度（granularity）。粒度是所有量化配置里最重要的一个旋钮：

图 1-2｜粒度谱系（示意矩阵远小于真实尺寸）。真实模型还有更细的变体：激活按每个 token 现算一对 scale（per-token dynamic），FP8 训练按 1×128 / 128×128 的小块配 scale（第 3 讲）。

粒度(s,z) 数量典型场景额外开销
per-tensor整个张量 1 对激活的粗粒度量化、端侧静态 INT8几乎为零
per-channel每行（输出通道）1 对权重量化的基本盘极小（通道数个 scale）
per-group每 group_size 个数 1 对（常 64 或 128）4-bit 权重量化标配（GPTQ/AWQ）scale 存储涨到可感知，但相对 4-bit 权重仍小
per-token / per-block每个 token / 小块现算 1 对激活量化（W8A8、FP8 训练）需在线统计 min/max，kernel 要融合这个操作
为什么激活偏爱细粒度激活的分布随输入变化剧烈：这个 token 平平无奇，下个 token 冒出离群大值。固定一整套格子容易「爆表」，所以激活宁可每次现算 scale（动态量化），或把切分粒度做细（per-token / per-block）——粒度细一点，离群值的影响就被隔离在一小块里。第 3 讲会把这条线走完。

4. 量化误差：舍入与裁剪

量化误差只有两个来源，所有的「误差分析」都在围绕它们做文章：

  1. 舍入误差（rounding error）：就近入座的差价。上界是半个格子间距 \(s/2\)——格子越细（\(s\) 小、粒度细）误差越小。
  2. 裁剪误差（clipping error）：区间外的值被强行压回边界。单个误差可能很大（差出一整个区间），但只要分布尾部数据少，发生率就低。

两者构成一对跷跷板：区间取大一点 → 几乎没人被裁剪，但格子铺得稀疏，舍入误差变大；区间取小一点 → 格子细密，但尾部数据被砍。怎么取区间，没有免费午餐，只能按数据的实际形状权衡。

4.1 手算一个完整例子

取 6 个权重 \(\{-0.9,\ -0.15,\ -0.05,\ 0.1,\ 0.2,\ 0.95\}\)，4-bit 非对称量化，区间 \([-1, 1]\)：\(s = (1-(-1))/15 = 0.125\)，\(z = 8\)。逐个走公式 \(q = \mathrm{clip}(\mathrm{round}(x/0.125)+8,\,0,\,15)\)、\(\hat{x} = 0.125(q-8)\)：

5. 校准：区间怎么定

「按数据实际形状定区间」听起来要未卜先知，实际操作叫校准（calibration）：拿几百条有代表性的样本喂给模型，记录每层的数据分布，然后选一种准则把区间定下来。权重是静态的（训练完就固定），直接统计即可；激活随输入变化，所以校准的意义主要在激活，以及端侧「静态量化」场景（离线把激活的 scale 也定死）。

准则做法优点缺点 / 适用
Min-Max区间 = 恰好覆盖 \([\min, \max]\)零裁剪误差，简单到不可能出错一个离群值就能把区间撑爆，剩下所有数陪它用粗格子——权重常用，激活慎用
Percentile砍掉分布两端各 0.1%~1% 的尾部，区间盖住其余 99%+在 min-max 基础上免疫离群值被砍的尾部吃裁剪误差；阈值要调
MSE 最小化网格搜索多个候选区间，选「量化再还原后与原值差的平方和」最小的直接优化最终关心的量，鲁棒多算几遍量化-反量化，校准慢一点；许多 SOTA 管线的默认
熵 / KL 散度把分布直方图压成 \(2^b\) 桶，选「压完与原分布差异（KL）最小」的切法保留分布形状信息TensorRT 经典方案；实现稍复杂
直觉校准准则的选择，本质是回答「更怕哪种错」：几乎不想裁坏任何数 → Min-Max；愿意牺牲尾部换取整体更细的格子 → Percentile / MSE；在乎输出分布整体不走样 → KL。GPTQ、AWQ 这类算法则在「定区间」之外更进一步——直接优化「量化后这一层的输出误差」，第 2 讲展开。

6. 一瞥非均匀量化：为什么还有 FP8

本讲的格子是均匀的——每格一样宽。但第 0 讲的浮点数天然是非均匀的：指数结构让 0 附近格子极密、远离 0 处格子极宽。这恰好匹配神经网络数据的形状：绝大多数值挤在 0 附近，少数离群值很大——均匀格子要在「照顾 0 附近」和「盖住离群值」之间挣扎，浮点格子两头都占了便宜。

这就是 FP8（E4M3 / E5M2）在激活量化里越来越流行的原因之一：不用特判离群值，格子自动「近 0 密、远 0 疏」。代价是浮点格子的乘法硬件比整数格子贵——所以 INT8 在成熟部署里依然是主力。两种格子各有地盘：权重（分布规整）用 INT，激活（分布长尾）用 FP 或细粒度 INT。第 3 讲的 W8A8 和 FP8 训练会把这个权衡讲透。

严格说，浮点量化的「格子宽度」随数量级指数变化（相邻可表示数之比近似 \(2^{1/\text{尾数位数}}\)），并非严格「每格等比」，但「近 0 密、远 0 疏」的定性结论成立。

7. 自查清单

下面 8 个问题都能答上来（最好动笔算），第 1 讲就过关了：

  1. 写出反量化公式，并说明 \(s\) 和 \(z\) 各管什么。（答：\(\hat{x}=s(q-z)\)；\(s\) 是格子间距，\(z\) 是真值 0 所在的格子号）
  2. 为什么一定要让 0 被精确表示？（答：网络里 0 无处不在——padding、ReLU 输出、对称结构；0 有偏差会系统性传播）
  3. 权重量化常用对称还是非对称？激活呢？为什么？（答：权重对称——分布以 0 为中心且省一步减法；激活常非对称/细粒度——分布偏一侧且随输入变化）
  4. GPTQ/AWQ 4-bit 权重的标准粒度配置？（答：per-group，group_size = 128）
  5. 量化误差的两种来源，上界各是多少量级？（答：舍入 ≤ s/2；裁剪可达一整个区间，但发生率低）
  6. 区间取大取小的代价各是什么？（答：大→格子稀、舍入误差大；小→尾部被裁、裁剪误差大）
  7. 四种校准准则分别适合什么顾虑？（答：零裁剪→Min-Max；免疫离群→Percentile；直接优化还原误差→MSE；保分布形状→KL/熵）
  8. 激活量化里 FP8 相对均匀 INT 的先天优势？（答：非均匀格子近 0 密远 0 疏，天然匹配长尾分布，离群值不吃掉全场分辨率）
